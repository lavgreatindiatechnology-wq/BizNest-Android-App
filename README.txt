BIZNEST ANDROID APP

Website:
https://biznest.greatindia.technology/

App Name:
BizNest

Package:
technology.greatindia.biznest

Included:
- Android WebView app
- Uploaded BizNest logo as launcher icon
- Website login/session support
- File upload chooser support
- Back button navigation
- GitHub Actions automatic APK build
- GitHub Actions automatic AAB build

HOW TO BUILD:
1. Upload this complete Android project to a GitHub repository.
2. Open GitHub -> Actions.
3. Run "Build BizNest Android APK and AAB".
4. After build finishes, download:
   - BizNest-APK
   - BizNest-AAB

IMPORTANT:
The generated AAB is unsigned. For Google Play Store publishing,
a signed release AAB is required.
